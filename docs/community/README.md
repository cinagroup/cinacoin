## Community Guidelines

### General Conduct

- **Be respectful.** Treat everyone with courtesy, regardless of experience level.
- **Be constructive.** Critique ideas, not people.
- **Stay on topic.** Each channel has a purpose — use the right one.
- **No spam.** Unsolicited promotions, link-dumping, or repetitive posts will be removed.
- **No harassment.** Zero tolerance for hate speech, doxxing, or personal attacks.

### Language

English is the primary language for all channels. Use translation tools if needed — we welcome contributors from all backgrounds.

### Code of Conduct

This community follows the project's [Code of Conduct](../../CODE_OF_CONDUCT.md). By participating, you agree to abide by it. Violations may result in warnings, temporary mutes, or permanent bans depending on severity.

## Where to Ask What

| Question Type | Best Channel |
|---------------|-------------|
| "How do I…?" / Getting help | Discord `#support` or Telegram |
| Bug reports | [GitHub Issues](https://github.com/your-org/onux/issues) |
| Feature ideas & RFCs | GitHub Discussions or Discord `#dev` |
| Show your project | Discord `#showcase` |
| Official announcements | Discord `#announcements` and Telegram |
| Security vulnerabilities | See [SECURITY.md](../../SECURITY.md) — **do not post publicly** |

## Support vs Development

- **Support channels** (`#support`, Telegram) — for users seeking help with integration, setup, and usage.
- **Development channels** (`#dev`, GitHub Discussions) — for contributors discussing architecture, PRs, roadmap, and technical design.

Please keep these separate so support questions don't get lost in technical debates, and dev discussions aren't derailed by beginner questions.

## Getting Involved

1. **Join** our channels above
2. **Introduce yourself** in Discord `#general` or Telegram
3. **Read** the pinned messages and FAQ
4. **Contribute** — check [CONTRIBUTING.md](../../CONTRIBUTING.md) for how to get started
5. **Help others** — the best community members are the ones who lift each other up
