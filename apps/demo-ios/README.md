# Cinacoin iOS Demo

Demo app showcasing the Cinacoin iOS SDK with AppKit architecture.

## Features

- **Connect**: Wallet connection using AppKit UI components
- **Auth**: Social login (Google, GitHub, Discord) and email authentication
- **Smart Account**: ERC-4337 smart account creation and deployment
- **Chains**: Browse and switch between supported EVM chains

## Setup

1. Replace `YOUR_PROJECT_ID` with your WalletConnect project ID
2. Configure OAuth credentials in Auth Service
3. Build and run in Xcode 15+

## Requirements

- iOS 16.0+
- Xcode 15.0+
- Swift 5.9+
