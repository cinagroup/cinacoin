# XRPL adapter.

> `@cinacoin/adapter-xrpl` — XRP Ledger adapter for CinaCoin.

## Installation.

```bash
npm install @cinacoin/adapter-xrpl
```

## Overview.

Enable XRP Ledger interactions including XRP transfers, token operations (issued currencies), and NFT interactions.
