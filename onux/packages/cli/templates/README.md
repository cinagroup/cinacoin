# Cinacoin CLI Templates

This directory contains source template files used by the `cinacoin template` command.

## Available Templates

| Template | Description |
|----------|-------------|
| `minimal` | Bare minimum Cinacoin connection setup |
| `wallet` | Full wallet UI with balance and transactions |
| `defi` | DeFi app with token swap and liquidity pools |
| `nft` | NFT marketplace with browsing and collection management |
| `game` | GameFi template with session keys and on-chain game state |

## Usage

```bash
npx @cinacoin/cli template <name>
npx @cinacoin/cli template minimal
npx @cinacoin/cli template wallet
npx @cinacoin/cli template --list
```
