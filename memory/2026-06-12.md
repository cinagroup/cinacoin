### Lessons Learned
- Demo DApp React didn't have Tailwind configured despite using Tailwind classes - had to replace all with inline styles
- Vue SDK packages need special build configuration (vue-tsc + vite, not tsup) for `.vue` files
- Cloudflare Pages projects need to be created before first deployment
- Next.js static export requires `output: 'export'` in next.config.js
