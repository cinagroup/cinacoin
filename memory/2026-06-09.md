## Auth Service 注册登录流程调试 (01:35-02:30 UTC)

### 问题发现与修复

#### 1. JWT_REFRESH_SECRET 缺失
- **问题**: 登录时返回 500 错误
- **原因**: 代码需要 `JWT_REFRESH_SECRET` 环境变量，但只配置了 `JWT_SECRET`
- **修复**: 添加 `JWT_REFRESH_SECRET` 到 wrangler.toml 和 Cloudflare secrets

#### 2. PBKDF2 迭代次数过高
- **问题**: 注册时返回 500 错误
- **日志**: `Pbkdf2 failed: iteration counts above 100000 are not supported (requested 600000)`
- **原因**: Cloudflare Workers Web Crypto API 限制 PBKDF2 最多 100,000 次迭代
- **修复**: 将 `PBKDF2_ITERATIONS` 从 600,000 降至 100,000
- **文件**: `workers/auth-service/src/lib/password.ts`

#### 3. 数据库表结构不完整
- **问题**: 注册时返回 "Failed to register user"
- **原因**: 数据库缺少 `display_name`、`role`、`last_login_at` 列
- **修复**: 执行 ALTER TABLE 添加缺失列
```sql
ALTER TABLE users ADD COLUMN display_name TEXT;
ALTER TABLE users ADD COLUMN role TEXT DEFAULT 'user';
ALTER TABLE users ADD COLUMN last_login_at INTEGER;
```

#### 4. mfa_methods 表缺失
- **问题**: 登录时返回 500 错误
- **日志**: `D1_ERROR: no such table: mfa_methods: SQLITE_ERROR`
- **原因**: 代码引用了 `mfa_methods` 表但迁移文件没有创建它
- **修复**: 手动创建 mfa_methods 表
```sql
CREATE TABLE IF NOT EXISTS mfa_methods (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL,
  type TEXT NOT NULL,
  is_enabled INTEGER NOT NULL DEFAULT 0,
  totp_secret TEXT,
  totp_verified INTEGER NOT NULL DEFAULT 0,
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL,
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);
```

#### 5. sessions 表字段问题
- **问题**: 登录时返回 "Failed to login"
- **原因**: 
  - `refresh_token_hash` 列有 NOT NULL 约束但未插入
  - `created_at` 列是 INTEGER NOT NULL 但未插入
  - `issued_at` 和 `expires_at` 是 TEXT 类型但传入数字
- **修复**: 更新 `token-rotation.ts` 中的 INSERT 语句，添加所有必需字段

#### 6. hashToken 异步调用问题
- **问题**: Token 刷新失败
- **原因**: `hashToken` 是异步函数，但调用时没有 `await`
- **修复**: 在 `rotateRefreshToken`、`detectTokenReuse` 等函数中添加 `await`

### 经验教训

1. **Cloudflare Workers 限制**: Web Crypto API 的 PBKDF2 迭代次数上限是 100,000，不是 OWASP 推荐的 600,000
2. **数据库迁移**: 代码和数据库表结构必须严格同步，缺少字段会导致运行时错误
3. **异步函数**: 必须检查函数签名，确保异步函数使用 `await` 调用
4. **日志调试**: `wrangler tail` 是调试 Cloudflare Workers 的关键工具
5. **限流清理**: 测试时频繁触发限流，需要定期清理 KV 中的限流记录
