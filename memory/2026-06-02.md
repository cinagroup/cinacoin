# Dashboard Login Redirect Loop — 2026-06-02

## Issue
After wallet login on dash.cinacoin.com/login, user gets redirected back to login page.

## Root Cause
In `AuthProvider.tsx`, the `doLogin` function called `signAndVerify` which returned the signature, but **never saved the session to localStorage**. After the component re-rendered, `getSession()` returned `null`, causing the `AuthGuard` to redirect back to `/login`.

The `auth.ts` file had a `login()` function that did save the session, but `AuthProvider.doLogin` wasn't using it — it called individual functions instead.

## Fix
Added `saveSession()` call in `AuthProvider.doLogin` after successful signing:
```ts
const session = {
  address: walletAddress,
  signature,
  nonce,
  timestamp: Date.now(),
  expiresAt: Date.now() + 24 * 60 * 60 * 1000,
};
saveSession(session);
```

Also added `saveSession()` export to `auth.ts`.
