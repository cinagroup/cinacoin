## 二、功能模块全景

### 2.1 核心连接层
- **Core SDK** — 自托管钱包连接核心工具包
- **Core UI** — Lit 构建的 Web Components
- **Cinacoin v2** — 完整协议实现（pairing/session/crypto）
- **Custom Connectors** — 自定义钱包连接器接口
- **Wallet Buttons** — 独立连接按钮（无模态框）
- **Wallet Recommender** — 智能钱包推荐引擎
- **Multiwallet** — 多钱包同时连接与管理

### 2.2 链适配器（10 条非 EVM）
- adapter-bitcoin（Unisat/Leather/OKX/Xverse/SatsConnect）
- adapter-solana（Phantom/Solflare/Wallet Standard）
- adapter-ton（Jetton 支持）
- adapter-near（NEAR/Here/Meteor）
- adapter-starknet（Argent X/Braavos，原生 AA）
- adapter-sui（Sui Wallet/Ethos/Suiet/Martian）
- adapter-cosmos（Keplr/Leap）
- adapter-hedera（Blade/HashPack/Kantara）
- adapter-tron（TronWeb/TRC20）
- adapter-xrpl（Xaman/Fireblocks/Ledger）

### 2.3 身份认证
- **SIWE** — EIP-4361 Sign-In with Ethereum
- **SIWX** — 跨链统一认证（EVM+Solana+Bitcoin）
- **Social Login** — OAuth2/邮箱登录 + HD 钱包派生
- **Passkey Auth** — WebAuthn 生物识别认证
- **Embedded Wallet** — 邮箱/社交/手机嵌入式钱包

### 2.4 账户抽象（ERC-4337）
- **AA SDK** — 智能账户/付费大师/Bundler 客户端
- **Bundler** — UserOperation 发送与管理
- **Paymaster** — Gas 赞助
- **Gas Sponsorship** — 企业级 Gas 赞助
- **Session Keys** — 临时签名密钥（策略+社交恢复）

### 2.5 金融功能
- **Swap SDK** — 多 DEX 聚合 + 滑点保护
- **On-Ramp SDK** — 多提供商法币→加密货币入口
- **Payment Flow** — 完整买/发/收支付 UI
- **Pay UI** — Swap & On-Ramp 组件
- **Batch Transaction** — 原子多操作构建器
- **Gas Estimator** — EIP-1559 + Solana compute budget
- **Deposit** — 交易所充值功能

### 2.6 安全与合规
- **Verify SDK** — 合约安全评分 + 钓鱼检测
- **KYC/AML** — 交易合规筛查
- **Travel Rule** — FATF 旅行规则合规（IVMS101 格式）
- **ERC-6492** — 合约签名验证
- **Wallet Recovery** — Shamir 秘密分享多提供商恢复

### 2.7 基础设施服务
- **Relay Server** — Cinacoin HTTP/WebSocket 中继
- **RPC Proxy** — 链路由/缓存/限速
- **Keys Server** — 密钥存储/加密/会话管理
- **Notify Server** — Push/Email/Webhook 通知
- **Push Server** — APNs/FCM 推送（设备注册+限速）
- **Analytics** — GDPR 合规事件追踪
- **Blockchain API** — ENS/余额历史/交易查询
- **TX Indexer** — 链上事件监听 + SQLite REST API
- **NFT Display** — 多链 NFT 获取与展示

### 2.8 跨链
- **Cross-Chain Contracts** — HTLC 原子交换智能合约
- **Cross-Chain Sync** — EVM/Solana 统一账户状态同步

### 2.9 开发工具
- **CLI** — init/add/build/test 命令行工具
- **Codemod** — Web3Modal/AppKit → Cinacoin 自动迁移
- **Testing** — Mock 提供商/钱包/链/交易
- **Integration Tests** — Sepolia/Amoy 等真实测试网
- **Perf Benchmarks** — P50/P95/P99 性能回归检测
- **Chain Registry** — CAIP-2 兼容，自动生成
- **Wallet Registry** — 100+ 钱包元数据
- **Explorer API** — 钱包/发现/Logo

### 2.10 前端框架（12 个）
React, Vue, Angular, Svelte, Next.js, Nuxt, React Native, Flutter, iOS Swift, Android Kotlin, Unity C#, .NET

### 2.11 设计系统
- Design Tokens — 白牌 UI 令牌
- UI Theme — 动画和基础组件

### 2.12 应用展示层（12 个）

### 3.3 核心差异化优势

1. **唯一完整自托管的全栈 Web3 连接方案** — 零供应商锁定
2. **最广泛非 EVM 覆盖** — 10 条原生适配器 vs 竞品 3-5 条
3. **SIWX 跨链统一认证** — 行业首创 EVM+Solana+Bitcoin 统一登录
4. **企业合规全栈** — KYC/AML + Travel Rule + Verify 唯一完整方案
5. **超低部署成本** — Cloudflare Workers 免费/低价 vs 竞品 $100+/月 SaaS
6. **账户抽象端到端** — AA SDK + Bundler + Paymaster + Session Keys
7. **12 框架全覆盖** — Web/Mobile/游戏全平台
8. **一键迁移** — Codemod 自动从 Web3Modal/AppKit 迁移

### 3.4 劣势与风险

1. **商业成熟度** — 新项目 vs Cinacoin 多年行业积累
2. **社区规模** — 无社区 vs Cinacoin 数百万开发者
3. **钱包生态合作** — 需建立钱包端合作关系
4. **生产验证** — 缺少大规模生产环境验证
5. **文档完善度** — 新构建中
6. **品牌认知** — 零知名度
