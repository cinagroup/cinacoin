| `.github/workflows/deploy-docs.yml` | Updated build paths from VitePress to Docusaurus |

# 2026-06-10 Memory Log

## 📸 Docs Site Screenshot Test & Fixes

### User Request (13先生)
截图测试 https://cinacoin.com/docs/ 页面，修复发现的错误。

### Issues Found
1. **308 Redirect Losing `/docs/` Prefix**: `/docs/guide/quick-start` → `/guide/quick-start/` (404)
   - Root cause: Docusaurus `trailingSlash` mismatch with Cloudflare Pages routing
2. **CI Workflow Broken**: `deploy-docs.yml` referenced old VitePress paths (`docs/.vitepress/dist`) instead of Docusaurus (`build/`)
3. **`package-lock.json` Missing from Git**: Caused `npm ci` to fail in GitHub Actions
4. **`baseUrl` Misconfiguration**: Was `/` but site is deployed at `/docs/` under `cinacoin.com`

### Fixes Applied
| File | Change |
|------|--------|
| `apps/docs-site/docusaurus.config.ts` | Set `trailingSlash: false`, `baseUrl: '/docs/'`, `url: 'https://cinacoin.com'` |
| `apps/docs-site/.gitignore` | Removed `package-lock.json` exclusion |
| `.github/workflows/deploy-docs.yml` | Updated build paths from VitePress to Docusaurus |

### Test Results (All Pass)
| Page | URL | Status |
|------|-----|--------|
| Docs Home | `/docs/` | ✅ 200 |
| Quick Start | `/docs/guide/quick-start` | ✅ 200 |
| Installation | `/docs/guide/installation` | ✅ 200 |
| API Core SDK | `/docs/api/core-sdk` | ✅ 200 |

### Architecture Note
Router Worker (`workers/router/src/index.ts`) strips `/docs` prefix when proxying `cinacoin.com/docs/*` → `cinacoin-docs.pages.dev/*`. Docusaurus `baseUrl: '/docs/'` generates correct asset paths for the proxied URLs.
