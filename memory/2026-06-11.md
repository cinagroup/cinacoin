### Key Technical Lessons
- Cloudflare Workers: use `c.env.ENVIRONMENT` not `process.env.ENVIRONMENT`
- `@noble/hashes/sha3` → `@noble/hashes/sha3.js` (explicit .js extension required)
- Analytics worker name is `cinacoin-analytics` NOT `cinacoin-analytics-prod`
- Router service binding must not specify `environment = "production"` for non-environment-scoped workers
- D1 databases need schema applied separately from worker deployment
- Running 5 wrangler deploy processes simultaneously causes OOM (SIGKILL) - deploy sequentially
