## 2. 详细分析

### 2.1 框架适配质量

**React** (7.5/10)
- ✅ `useCinacoin()` hook 设计合理，支持 `useSyncExternalStore`
- ✅ `CinacoinProvider` 正确使用 React Context
- ⚠️ 缺少 `useEffect` cleanup 对 WebSocket 连接的清理
- ⚠️ 未使用 `React.memo` 优化高频重渲染组件

**Vue** (7.0/10)
- ✅ `useCinacoin()` composable 符合 Vue 3 Composition API 规范
- ✅ `createCinacoinPlugin()` 正确注册全局属性
- ⚠️ 缺少 `onUnmounted` 清理逻辑
- ⚠️ 未使用 `shallowRef` 优化大对象响应性

**Angular** (7.0/10)
- ✅ `CinacoinModule` 正确使用 `forRoot()` 模式
- ✅ `CinacoinService` 使用 `Injectable` + `providedIn: 'root'`
- ⚠️ 缺少 `OnDestroy` 生命周期清理
- ⚠️ 未使用 Angular Signals（Angular 17+ 推荐）

**Svelte** (7.5/10)
- ✅ 使用 Svelte stores 管理状态
- ✅ SvelteKit 适配正确处理 SSR
- ⚠️ 缺少 `$effect` cleanup (Svelte 5 runes)

**Next.js** (7.0/10)
- ✅ 同时支持 App Router 和 Pages Router
- ✅ `'use client'` 边界正确
- ⚠️ 缺少 `dynamic import` 优化（Modal 应懒加载）

**Nuxt 3** (7.0/10)
- ✅ `defineNuxtModule` 正确使用
- ✅ `useCinacoin()` composable 可 SSR-safe
- ⚠️ 缺少 Nitro 插件集成

**React Native** (6.5/10)
- ✅ Bridge 连接原生模块
- ⚠️ 缺少 New Architecture (Fabric) 支持
- ⚠️ 无 Expo 适配

### 2.2 组件一致性 (7.0/10)

| 检查项 | 状态 |
|---|---|
| 跨框架 API 命名一致 | ⚠️ 部分不一致 (React `onConnect` vs Vue `@connect`) |
| Props/Events 规范 | ✅ 基本一致 |
| 错误类型统一 | ⚠️ 各框架错误对象结构不同 |
| TypeScript 类型导出 | ✅ 完整 |

### 2.3 Bundle Size (7.5/10)

| 包 | 大小 (min+gz) | 评估 |
|---|---|---|
| `@cinacoin/react` | ~18KB | ✅ 合理 |
| `@cinacoin/vue` | ~16KB | ✅ 合理 |
| `@cinacoin/angular` | ~22KB | ⚠️ 偏大 |
| `@cinacoin/svelte` | ~12KB | ✅ 最小 |
| `@cinacoin/core-ui` | ~35KB | ⚠️ 应拆分 |
| `@cinacoin/ui` | ~45KB | ❌ 过大 |

- ✅ ESM + subpath exports 支持 tree-shaking
- ⚠️ `@cinacoin/ui` 未做按需导入

### 2.4 SSR/SSG 兼容 (7.0/10)

- ✅ Next.js `dynamic(() => import(...), { ssr: false })` 支持
- ✅ Nuxt `<ClientOnly>` 兼容
- ⚠️ `core-ui` 中使用了 `document` 全局对象（SSR 不安全）
- ⚠️ Modal 组件未处理 hydration mismatch

### 2.5 可访问性 a11y (6.0/10) ⚠️

- ⚠️ Modal 缺少 `role="dialog"` 和 `aria-modal="true"`
- ⚠️ QR Code 无 `aria-label`
- ⚠️ 键盘导航不完整（Tab trap 未实现）
- ⚠️ 焦点管理缺失（Modal 打开/关闭时焦点不转移）
- ✅ 颜色对比度符合 WCAG AA
- ⚠️ 屏幕阅读器测试未覆盖

### 2.6 主题系统 (8.0/10)

- ✅ CSS 变量驱动，支持运行时切换
- ✅ Dark/Light/Custom 三模式
- ✅ Design tokens 完整（颜色、间距、字体、圆角、阴影）
- ✅ `data-theme` 属性切换
- ⚠️ 缺少 `prefers-color-scheme` 媒体查询自动检测

### 2.7 国际化 (7.5/10)

- ✅ 支持 8 种语言 (en, zh, ja, ko, es, fr, de, ru)
- ✅ 消息格式 ICU 兼容
- ✅ 复数形式支持
- ⚠️ 缺少 RTL 布局支持 (ar, he)
- ⚠️ 日期/数字格式化未集成 Intl API

### 2.8 Demo 应用 (7.0/10)

| Demo | 框架 | 功能覆盖 | 状态 |
|---|---|---|---|
| demo-react | React | 连接/签名/转账 | ✅ 可用 |
| demo-vue | Vue 3 | 连接/签名 | ✅ 可用 |
| demo-dapp-react | React | DApp 集成示例 | ✅ 可用 |

## 4. 优化建议

### 短期 (1-2 周)
1. **[C1/C2]** 修复 SSR hydration — 使用 `typeof window !== 'undefined'` 守卫
2. **[H1]** 添加 Modal ARIA 属性 — `role="dialog"`, `aria-modal`, `aria-labelledby`
3. **[H2/H5]** 添加连接清理 — React `useEffect` return, Vue `onUnmounted`
4. **[M2]** 添加 `prefers-color-scheme` 媒体查询

### 中期 (1 个月)
5. **[H3]** 拆分 `@cinacoin/ui` — 按需导入 `@cinacoin/ui/modal`, `@cinacoin/ui/button`
6. **[H4]** 添加 RTL 支持 — `dir="rtl"` + CSS logical properties
7. **[M1]** Angular 迁移到 Signals
8. **[M4]** 实现 Modal Tab trap + 焦点管理

### 长期 (2-3 个月)
9. **[M3]** React Native Expo 适配器
10. **[M6]** React Native New Architecture (Fabric) 支持
11. 完整 a11y 测试套件 (axe-core + jest-axe)
12. 各框架 E2E 测试 (Playwright for web, Maestro for mobile)
