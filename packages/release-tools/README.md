# @cinacoin/release-tools

Cinacoin release and publishing pipeline tools.

> **Note:** This is a private package — not published to npm.

## Scripts

- `publish:npm` — Publish all packages to npm
- `publish:npm:dry-run` — Dry-run npm publish
- `publish:android` — Publish Android library
- `publish:ios` — Publish iOS library
- `publish:dotnet` — Publish .NET package
