# @cinacoin/ui

Shared Cinacoin UI components (Brand, SiteHeader, SiteFooter) — framework-agnostic React.

## Installation

```bash
npm install @cinacoin/ui
```

## Usage

```tsx
import { Brand, SiteHeader, SiteFooter } from "@cinacoin/ui";

function App() {
  return (
    <>
      <SiteHeader />
      <Brand />
      <SiteFooter />
    </>
  );
}
```
