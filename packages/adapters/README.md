# @cinacoin/adapters

Cinacoin wallet adapters — unified interface for MetaMask, WalletConnect, Coinbase, Phantom, Bitcoin, and more.

## Installation

```bash
npm install @cinacoin/adapters
```

## Usage

```typescript
import { getAdapters } from "@cinacoin/adapters";

const adapters = getAdapters();
```
